📡 APIs Utilizadas — Todas Gratuitas
● AwesomeAPI GRÁTISSEM CHAVE
economia.awesomeapi.com.br/json/last/USD-BRL,EUR-BRL,GBP-BRL
Câmbio em tempo real. Dólar, Euro, Libra, e 150+ moedas. Sem limite de requisições razoável. Dados do Banco Central e mercado interbancário. Ideal para forex.
● CoinGecko GRÁTISSEM CHAVE30 req/min
api.coingecko.com/api/v3/simple/price?ids=bitcoin,ethereum&vs_currencies=usd,brl
Preços de criptomoedas em tempo real. Bitcoin, Ethereum, e 10.000+ coins. Variação 24h, volume, market cap. Limite de 30 chamadas/minuto no free tier.
● Brapi GRÁTIS15min delay
brapi.dev/api/quote/PETR4,VALE3,ITUB4,BBAS3?token=SEU_TOKEN
Ações da B3, FIIs, ETFs, índices (Ibovespa, IFIX). Token gratuito no site. Delay de 15min. Inclui DY, P/L, variação. Até 15 tickers por chamada no free. Perfeito para o mercado brasileiro.
◆ Como usar no GitHub Pages:
1. Crie um repositório no GitHub (ex: market-dashboard)
2. Suba este arquivo como index.html
3. Vá em Settings → Pages → Source: main branch
4. Acesse em seuuser.github.io/market-dashboard
5. Para a Brapi, crie um token grátis em brapi.dev e substitua no código

⚠ Limitações do free tier: AwesomeAPI e CoinGecko funcionam direto. A Brapi precisa de token (gratuito) e tem delay de 15min. Para dados real-time da B3 sem delay, seria necessário API paga (ex: B3 API, Refinitiv).
